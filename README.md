## Historical evidence note

The retained long-form draft [`devto_bot_audit_FINAL.md`](devto_bot_audit_FINAL.md) reflects an earlier investigation/publication state and should not be treated as the current analytical standard.

Two counts in that artifact are easy to conflate:

- **1,409** — the full follower cohort audited at the documented snapshot;
- **897** — the high-confidence coordinated-pattern subset produced by the documented score threshold after false-positive review.

The draft's `899` headline is inconsistent with its own final table and is retained only as historical draft text. More importantly, later sections of that draft contain stronger marketplace/operator-mechanism interpretations than the available public evidence can independently establish. Its own limitations section correctly notes that IP/device linkage, purchase records, session data, payment records, and internal moderation telemetry were unavailable.

For current work, preserve the distinction between observed graph structure, coordinated-pattern classification, operational inference, and attribution.
